# 검증

1. `node scripts/check.mjs` 실행. ERROR 가 있으면 원인 파일과 줄을 찾아 고친 뒤 재실행한다.
   WARN 은 보고만 한다 (예시 이메일, 시안 문구는 운영 개시 전까지 의도된 상태).
2. 렌더링 확인이 필요하면 `node scripts/preview.mjs` 실행 후 `.preview/*.png` 를 Read 로 열어 본다.
   - 게시판 표가 비어 있거나 "자료를 불러오지 못했습니다" 가 보이면 `data/*.js` 문법 오류
   - 상세 본문이 안 보이면 본문 파일 경로·대소문자 확인
3. 결과를 "오류 n건 / 경고 n건" 과 고친 내용으로 요약한다.
