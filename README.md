# 온실가스감축인지 운영시스템 접속(SSL VPN) 신청 안내 페이지

GitHub Pages 배포용 정적 페이지입니다.

## 폴더 구조

```
index.html          안내 페이지 (게시판 표는 비어 있고 JS가 채웁니다)
view.html           게시글 상세 (틀만 있고 JS가 채웁니다)
style.css           공용 스타일 — 색은 맨 위 :root 변수만 고치면 됩니다
assets/app.js       공용 스크립트 — 평소 고칠 일 없습니다
data/
  site.js           기관명·전화·이메일 등 사이트 공통 정보
  posts.js          게시글 목록 (공지사항 + 자료실)
  notice/<id>.html  공지사항 본문
  archive/<id>.html 자료실 본문
files/              첨부파일 실물
```

## 글 추가하는 법 (2단계)

### 1. 본문 파일 만들기
`data/notice/5.html` (자료실이면 `data/archive/5.html`) 을 만들고 본문만 적습니다.
`<p> <ul> <h3> <table>` 을 그대로 쓰면 됩니다. `<html>`, `<head>` 는 필요 없습니다.

```html
<p>안내 말씀드립니다.</p>
<h3>세부 내용</h3>
<ul>
  <li>첫째</li>
  <li>둘째</li>
</ul>
```

### 2. `data/posts.js` 의 `posts` 배열 **맨 앞**에 한 줄 추가

```json
{
  "board": "notice", "id": "5", "date": "2026-10-15",
  "title": "글 제목",
  "writer": "탄소예산지원부",
  "files": [
    { "name": "첨부파일.pdf", "path": "files/첨부파일.pdf", "type": "PDF", "size": "1.2MB" }
  ]
}
```

끝입니다. index.html·view.html 은 건드리지 않습니다.

### 자동으로 처리되는 것
- **번호** — 날짜순으로 자동 매깁니다. 직접 적지 마세요.
- **NEW 배지** — 등록일이 14일 이내면 자동으로 붙습니다. 기간은 `data/posts.js` 의 `newDays` 로 조절합니다.
- **전체 건수** — 글 개수에서 자동 계산합니다.

### 자주 쓰는 옵션
| 넣는 값 | 결과 |
|---|---|
| `"pin": true` | 번호 대신 '공지'로 표시되고 목록 맨 위에 고정 |
| `"badge": "서식"` | 제목 앞에 초록 배지 |
| `"files": []` | 첨부파일 없음 |
| `"path": ""` | '준비 중'으로 표시, 다운로드 링크 안 걸림 |

## 글 삭제
`data/posts.js` 에서 해당 줄을 지웁니다. 본문 html 파일은 남겨 둬도 화면에 나오지 않습니다.

## 연락처·이메일 변경
`data/site.js` 한 곳만 고치면 유틸바·제출처·문의처·푸터에 모두 반영됩니다.

## 주의사항 (GitHub Pages)

1. **로컬에서 `index.html` 을 더블클릭하면 게시글 본문만 안 보입니다.**
   연락처·게시판 목록은 정상으로 나오고, 상세 본문(`data/notice/*.html`)만
   `file://` 제약으로 못 읽습니다. 본문까지 확인하려면 폴더에서 아래를 실행하고
   `http://localhost:8000` 으로 접속하세요.
   ```
   python -m http.server 8000
   ```
   GitHub Pages에 올라가면 전부 정상입니다.

2. **경로 대소문자를 구분합니다.** `Files/` 와 `files/` 는 다른 경로입니다.
   윈도우에서는 멀쩡하다가 배포 후 404가 나는 전형적인 원인입니다.

3. **배포 반영에 수 분 걸릴 수 있습니다.** 안 바뀌어 보이면 강력 새로고침(Ctrl+F5).

4. 첨부파일 이름에 공백·특수문자가 있으면 경로를 URL 인코딩하거나 영문 파일명을 권합니다.
